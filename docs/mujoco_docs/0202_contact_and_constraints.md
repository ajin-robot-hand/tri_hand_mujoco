# MuJoCo 접촉 역학과 구속조건 모델 (Contact & Constraints)

> 원문 출처: [MuJoCo Documentation - Computation](https://mujoco.readthedocs.io/en/stable/computation/index.html)  
> 본 문서는 MuJoCo의 계산(Computation) 챕터 중 **부드러운 접촉(Soft Contact)의 물리적·수학적 원리, 4대 구속조건(등가, 마찰 손실, 한계, 접촉), 마찰 콘(Friction Cone), 핵심 파라미터(`solref`, `solimp`, `condim`)의 튜닝 가이드**를 정리한 제2편 문서입니다.

---

## 1. 부드러운 접촉 모델의 철학 (Soft Contact Model)

### (1) 왜 게임 엔진의 LCP(선형 상보성) 대신 볼록 최적화인가?
기존의 다체 물리 엔진(ODE, Bullet, PhysX 등)은 강체(Hard body) 접촉을 풀 때 **선형 상보성 문제(LCP: Linear Complementarity Problem)**를 사용합니다. LCP의 핵심 가정은 **엄격한 상보성(Strict Complementarity)**입니다:

$$f_{\text{normal}} \ge 0, \quad v_{\text{normal}} \ge 0, \quad f_{\text{normal}} \cdot v_{\text{normal}} = 0$$

- **엄격한 상보성의 현실적 모순**: 
  - 물체가 접촉면에 닿아 힘을 받는 동안($f > 0$)에는 법선 방향 속도가 반드시 0이어야 합니다($v = 0$).
  - 하지만 현실 세계의 모든 물리적 물체(특히 로봇의 고무 핑거팁이나 생체 조직)는 접촉 시 미세하게 압축되고 변형(Deformation)됩니다.
  - 침투 후 튕겨 나오거나 표면이 복원되는 과정에서는 **밀어내는 힘($f > 0$)과 복원 속도($v > 0$)가 동시에 양수**가 됩니다. 즉, 물리적으로는 상보성이 깨지는 것이 지극히 자연스럽습니다.
- **연산 복잡도와 최적화의 한계**:
  - 마찰이 포함된 LCP는 수학적으로 **NP-hard** 문제입니다. 게임 엔진들은 연산 속도를 위해 거친 근사 휴리스틱을 쓰기 때문에 물체가 떨리거나(jittering), 튕기거나, 폭발하는 현상이 발생합니다.
  - 또한 LCP는 미분 불가능한 불연속면을 만들어 로보틱스 궤적 최적화나 역역학(Inverse Dynamics) 계산을 불가능하게 만듭니다.

### (2) MuJoCo의 혁신: 가우스 최소 구속 원리의 확장
MuJoCo는 엄격한 상보성 조건을 과감히 제거하고, 이를 부드러운 비용 함수로 대체하여 접촉 물리를 **유일한 전역 최적해를 갖는 볼록 최적화(Convex Optimization) 문제**로 정식화했습니다:

1. **가우스의 최소 구속 원리 (Gauss's Principle of Least Constraint)**:
   - 구속조건이 없는 자유 가속도 $M^{-1}\tau$에 대해, 구속조건 $J \dot{v} = a_{\text{ref}}$를 만족하면서 관성 가중 가속도 오차 $\| \dot{v} - M^{-1}\tau \|_M^2$를 최소화하는 방향으로 실제 가속도가 결정된다는 고전 역학 원리입니다.
2. **소프트 구속조건(Soft Constraint)으로의 확장**:
   - 구속조건에 가상의 변형 변수(Deformation slack variable)와 **대각 정규화 행렬 $R$ (Regularizer)**을 도입합니다.
   - $R \to 0$이면 단단한 강체 구속(Hard constraint)에 근접하고, $R \to \infty$이면 힘이 전혀 작용하지 않는 무한히 부드러운 상태가 됩니다.
   - 이를 통해 **수치적 안정성, 현실적인 접촉 완충, 해석적 미분 가능성, 유일한 역역학 성립**이라는 네 마리 토끼를 모두 잡았습니다.

## 2. 구속조건 4가지 유형 (Constraint Types)

MuJoCo 시스템의 총 구속조건 수 `nc`(`mjData.nefc`)는 다음 4가지 요소가 활성화될 때마다 누적되며, 전체 자코비안 $J$의 행(row)을 구성합니다:

```
[총 구속조건 nc] = [등가 구속(Equality)] + [마찰 손실(Friction Loss)] + [한계(Limit)] + [접촉(Contact)]
```

### (1) 등가 구속 (Equality Constraints) — 잔차 $r(q) = 0$
기구학 트리 외부에 강제적인 기구학적 폐루프(Closed loop)나 상대적 결합을 생성합니다.
- `connect` (차원: 3): 두 바디의 특정 앵커 포인트를 하나로 묶어 트리 외부의 3D 볼 조인트를 형성.
- `weld` (차원: 6): 두 바디의 상대 위치와 3차원 상대 회전을 모두 고정 (용접).
- `joint` (차원: 1): 두 단일 관절(Hinge/Slide)의 위치를 다항식 관계($y - y_0 = a_0 + a_1(x - x_0) + \dots$)로 기계적 연동 (감속기, 랙앤피니언, 헬리컬 조인트 모사).
- `tendon` (차원: 1): 두 텐던의 길이를 연동.

### (2) 마찰 손실 (Friction Loss) — 정지 마찰 / 드라이 마찰
- 쿨롱 마찰과 달리 **수직 항력(하중)에 비례하지 않고, 관절/텐던 자체에 내재된 건식 마찰(Dry Friction)**입니다.
- 속도가 생기기 전부터 선제적으로 운동을 억제하므로 단순 댐핑과 달리 구속조건으로 처리됩니다.
- 한계 마찰력 $\eta$(`frictionloss`)를 상한으로 가지며, 통계학의 **후버 노름(Huber norm)** 원리를 이용해 속도가 0에 머물도록 유지합니다 (외력이 $\eta$를 넘어야 비로소 움직이기 시작함).

### (3) 한계 구속 (Limit Constraints) — 단방향 부등식
- 관절(`joint`)이나 텐던(`tendon`)의 가동 범위(`range="min max"`)를 제한합니다.
- 잔차 $r(q)$는 한계점까지의 남은 거리이며, 거리가 `margin` 이하로 떨어지는 순간 단방향 제약력이 활성화되어 한계 돌파를 방어합니다.

### (4) 접촉 구속 (Contact Constraints) — 점 접촉 역학
두 지오메트리(`<geom>`) 표면이 충돌할 때 생성되는 가장 정교한 구속조건입니다.
- 충돌 검출기는 두 충돌체 사이의 **접촉점(Point), 법선 벡터(Normal), 접촉 프레임(Contact Frame), 법선 거리(Distance)**를 계산합니다.
- 접촉 프레임의 **첫 번째 축($x$)이 항상 접촉 법선(Normal)**이며, 나머지 두 축($y, z$)이 접선 평면(Tangent plane)을 형성합니다.
- 거리가 음수($d < 0$)이면 표면 침투(Penetration)가 발생한 상태입니다.

## 3. 접촉 차원(`condim`)과 마찰 콘(Friction Cones)

### (1) 접촉 차원 (`condim`)의 물리적 의미

| `condim` | 허용력 및 자유도 | 마찰 계수 벡터 (`friction`) | 주요 적용 분야 |
| :---: | :--- | :--- | :--- |
| **`1`** | 법선 반발력 (Frictionless) | 없음 | 얼음판, 무마찰 베어링, 슬라이딩 가이드 |
| **`3`** | 법선력 + 2축 접선 미끄럼 마찰 | `[sliding]` (1개) | **(기본값)** 일반적인 블록, 바닥, 슬립 마찰 |
| **`4`** | 법선 + 접선 + **비틀림 마찰 (Torsional)** | `[sliding, torsional]` (2개) | **로봇 손가락 파지 (Grasping)**, 고무 패드 |
| **`6`** | 법선 + 접선 + 비틀림 + **구름 마찰 (Rolling 2축)** | `[sliding, torsional, rolling]` (3개) | 자동차 바퀴, 굴러가는 공, 볼 베어링 |

> [!IMPORTANT]
> **비틀림/구름 마찰계수의 단위는 왜 '길이(m)'인가?**  
> 일반 슬라이딩 마찰계수는 무차원($\mu$)이지만, 비틀림과 구름 마찰은 힘이 아닌 **토크(Torque)**를 생성해야 합니다.  
> 따라서 마찰 토크 $\tau_{\text{torsion}} \le \mu_{\text{torsion}} f_{\text{normal}}$ 수식이 성립하기 위해 $\mu_{\text{torsion}}$은 **길이 차원($\text{m}$)**을 갖습니다.  
> 물리적으로는 **접촉면이 눌리면서 생기는 접촉 원형 패치의 반경/직경**으로 해석할 수 있습니다.

### (2) 타원체 콘(Elliptic Cone) vs 피라미드 콘(Pyramidal Cone)
- **타원체 콘 (Elliptic)**: 물리적으로 엄밀한 원추형 마찰 한계면 ($f_{\text{normal}}^2 \ge \sum f_{\text{tangent}}^2 / \mu^2$).
- **피라미드 콘 (Pyramidal)**: 타원형 마찰 원뿔을 4개~10개의 모서리를 가진 다각뿔로 선형 근사한 형태.
- **소프트 접촉에서의 결정적 차이**:
  - 강체 접촉에서는 피라미드 모서리를 늘리면 타원체에 수렴하지만, **소프트 접촉에서는 페널티 함수의 등고선 형상 자체가 다르기 때문에 수렴하지 않습니다.**
  - 정밀한 로봇 손가락 조작 및 파지 시뮬레이션에서는 **타원체 콘(Elliptic Cone)**을 사용하는 것이 파지 안정성과 현실성이 훨씬 뛰어납니다.

## 4. 핵심 솔버 파라미터 듀오: solref와 solimp

MuJoCo의 모든 소프트 구속조건(접촉, 관절 한계, weld 등)의 물리적 거동은 **임피던스 곡선(`solimp`)**과 **가상 스프링-댐퍼(`solref`)** 두 파라미터의 결합으로 완성됩니다.

```
[침투 거리 r] ───► solimp (d 임피던스 계산: 0 ~ 1) ───► 정규화 행렬 R 산출
[침투 거리 r, 속도 Jv] ───► solref (k 강성, b 감쇠 계산) ───► 기준 가속도 a_ref 산출
                                       │
                                       ▼
                       구속 가속도 a_c = d · a_ref + (1 - d) · a_unconstrained
```

### (1) `solref`: 접촉 복원 동역학 (Spring-Damper)
구속조건 위반(침투)을 밀어내기 위한 목표 기준 가속도 $a_{\text{ref}}$를 계산합니다:

$$a_{\text{ref}} = - b (J v) - k r$$

일반적으로 강성 $k$와 감쇠 $b$를 직접 넣는 대신, 훨씬 직관적인 **표준 시간상수 형태 `solref="timeconst dampratio"`**를 사용합니다:
- **`timeconst` ($t_{\text{const}}$, 단위: 초)**:
  - 교란이 발생했을 때 평형점으로 복원되는 시간 스케일.
  - 값이 작을수록 단단한(stiff) 접촉이 되고, 값이 크면 푹신한 스펀지처럼 천천히 밀어냅니다.
  - **주의**: 시뮬레이션 타임스텝 $h$보다 너무 작으면($t_{\text{const}} < 2h$) 수치적으로 불안정해질 수 있습니다.
- **`dampratio` ($d_{\text{ratio}}$, 무차원)**:
  - 감쇠비 ($\zeta$).
  - **`1.0` (기본값)**: 임계 감쇠 (Critical damping). 진동이나 튕김 없이 가장 빠르게 정지 상태로 수렴.
  - `< 1.0`: 저감쇠 (탱탱볼처럼 통통 튐).
  - `> 1.0`: 과감쇠 (물속에서 움직이듯 끈적하게 복원).

### (2) `solimp`: 가변 임피던스 곡선 (Constraint Impedance)
접촉 강도(0: 힘 없음, 1: 완전 구속)를 나타내는 무차원 임피던스 $d$를 침투 거리에 따라 매끄럽게 가변시킵니다.

$$\texttt{solimp} = \left[ d_{\min}, \; d_{\max}, \; \text{width}, \; \text{mid}, \; \text{power} \right]$$

- 기본값: `[0.9, 0.95, 0.001, 0.5, 2]`
- **`dmin`, `dmax`**: 임피던스의 최소값과 최대값 (보통 0.9 ~ 0.99 수준).
- **`width` (m)**: 표면 완충층의 두께. 접촉 표면에서 이 깊이까지 들어가는 동안 임피던스가 서서히 증가합니다.
- **`mid`**: 곡선 변곡점의 상대적 위치 (0.5는 중앙).
- **`power`**: 보간 다항식의 지수 차수.

> [!TIP]
> **표면 떨림(Chattering) 없는 완충 접촉 만들기**  
> 가벼운 물체가 바닥에 닿을 때 바르르 떠는 현상은 표면 접촉 순간 힘이 너무 불연속적으로 세게 들어오기 때문입니다.  
> `solimp="0.01 0.95 0.01 0.5 2"` 처럼 $d_{\min}$을 작게 주고 `width`를 1cm(0.01) 정도 주면, 표면 살짝 닿았을 때는 부드럽게 감속하다가 깊이 눌릴 때 강하게 받쳐주어 떨림이 완전히 사라집니다.

### (3) `margin`과 `gap` 버퍼
- **`distance > margin + gap`**: 미접촉.
- **`margin < distance <= margin + gap`**: **비활성 접촉 (Inactive contact)**. 접촉 목록(`mjData.contact`)에는 잡히지만 반발력은 0. (센서 감지, 진공 점착력 인가용).
- **`distance <= margin`**: **활성 접촉 (Active contact)**. 실제 반발력 및 마찰력 생성.

## 5. tri_hand 프로젝트와의 연계 및 파지 튜닝 가이드

본 저장소의 3지 다관절 로봇 손(`tri_hand`) 환경에서 본 챕터의 이론은 직접적인 파지 성능을 좌우합니다:

1. **손가락 핑거팁의 접촉 차원 설정 (`condim="4"`)**:
   - `tri_hand`의 손가락 끝 지오메트리는 물체와 맞닿아 조작을 수행합니다.
   - 기본 `condim="3"`(미끄럼 마찰만)을 쓰면 손가락 끝에서 원통이나 구형 물체가 회전 토크를 버티지 못하고 팽이처럼 헛돌게 됩니다.
   - 핑거팁 geom에 **`condim="4"`**를 주고 `friction="1.0 0.005"`처럼 비틀림 마찰(두 번째 값, 단위 m)을 부여하면, 실제 실리콘 패드로 물체를 잡았을 때처럼 비틀림 회전을 견고하게 파지할 수 있습니다.
2. **관절 가동 한계 완충 (`solref` 조정)**:
   - `tri_hand` 서보 모터가 빠른 속도로 회전하여 관절 한계(`joint range`)에 도달할 때, 기본 강체 한계 설정은 순간적인 충격으로 반대 방향 튕김을 유발할 수 있습니다.
   - 관절에 임계 감쇠(`dampratio="1"`, `timeconst="0.02"`) 형태의 `solref`를 주면 한계 지점에 도달했을 때 기계적 댐퍼에 닿은 것처럼 부드럽게 멈춥니다.
3. **자가 충돌(Self-Collision)과 margin**:
   - `AGENTS.md` 지침에 따라 손가락 링크의 충돌 프리미티브(`group 3`)들이 조립 초기 상태에서 서로 닿지 않도록 여유 공간을 확보해야 하며, 필요 시 음수 `margin`을 약간 주어 초기 관통 폭발을 방지할 수 있습니다.

## 6. 권장 체크리스트 (Checklist)
